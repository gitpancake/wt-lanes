Every stop ends in exactly ONE of three final tool calls. `~/.claude/scripts/lane-done.sh` when the PR is open, the arbiter is green on the final sha, and every finding is addressed + pushed (or review skipped per repo policy) — it marks the lane DONE and flashes the tab green; never claim done without it. `~/.claude/scripts/lane-pause.sh <code> '<detail>'` with a code from ~/.claude/agent-state-vocab.md: review never settled → review; a person must release the PR → holland | human | prompt-owner; ambiguity not in the brief/plan, repeated test failure on one root cause, missing credential → ambiguity | test-loop | creds; a rate limit or vendor outage → external. `~/.claude/scripts/lane-handoff.sh <doc>` when context forces a session swap. A turn that ends with none of them shows on the cockpit as 'stopped without a pause code' and counts as a protocol breach.
